Google Dork Link Collector

Run a dork through the official Google Programmable Search API, then view, copy, and download the result URLs.

Limits: the free tier allows about 100 queries per day and paid usage may apply. Each dork returns at most 100 results (10 per page). This tool cannot collect every URL on the internet, and results may differ from google.com.
Settings: API credentials

Credentials stay in memory unless you tick the box, and are sent only to googleapis.com.

How to set up
  1. Create a Programmable Search Engine at programmablesearchengine.google.com and set it to search the entire web. Copy its Search engine ID (cx).
  2. In the Google Cloud Console, enable the Custom Search API for a project.
  3. Under APIs & Services > Credentials, create an API key.
  4. Paste the key and cx into Settings above, enter a dork, and press Start Collecting.

Use of the API is subject to Google's terms of service. Collected URLs are never visited or crawled by this page. No queries or results are stored.

Paste a raw dork or a full Google search URL (the q parameter is extracted). The query is sent exactly as typed.

Provider limits: 1 to 100 results total, 1 to 10 per page. Values outside the range are clamped.
